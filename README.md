# NarratoProV1

AI 驱动的高质量、生产级短剧营销视频生产系统。

## Agent 与开发者入口

开始任何设计、编码、审核或生产任务前，必须按以下顺序读取：

1. `AGENTS.md`
2. `PROJECT_INDEX.md`
3. `PROJECT_STATE.md`
4. `agent/CONTEXT_RECONSTRUCTION_PROTOCOL.md`
5. `PROJECT_INDEX.md` 为当前任务指定的文件

禁止只依赖聊天记录、压缩摘要或 Agent 自身记忆判断项目状态。

当前项目方向、完成度、下一步和阻断项以 `PROJECT_STATE.md` 为唯一状态入口；架构与规范的权威来源由 `PROJECT_INDEX.md` 路由。
