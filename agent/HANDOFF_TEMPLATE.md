# Task Handoff Template

Version: 1.0

```text
Handoff ID:
Date / Author:
Task Type / Active Role:

Objective:
Active Epic / Backlog ID:
Starting State Version:

Inputs Read:
- canonical files and versions

Decisions Made:
- decision + canonical destination

Files Changed:
- path + purpose

Validation Performed:
- exact command/check
- result

Completed:
- verified outcomes only

Not Completed:
- partial or deferred work

Workspace State:
- branch/status/running processes/external effects

Risks / Blockers / Open Decisions:
- item + owner/next action

Next Exact Step:
- one recoverable action

Project State Update:
- new state version or state_impact: none
```

Handoff 只摘要恢复所需事实。详细设计、日志和测试输出使用文件/ArtifactRef 链接，不复制进交接文本。
